# TeroPOS - Selected Technical Portfolio: https://app.teropos.com

This repository presents a limited and sanitised overview of TeroPOS, a full-stack point-of-sale application developed and deployed by Saranya Gunasekaram.

The complete production source code remains private to protect security-sensitive configuration, business logic and intellectual property.

## Project Overview

TeroPOS is a multi-vendor point-of-sale system designed to support product management, inventory operations, sales, receipts and administrative workflows.
